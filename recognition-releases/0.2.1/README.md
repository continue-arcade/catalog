# 离线识别数据

导入游戏时，即使没联网，Continue 也能用这张卡带里的文件指纹、编号和名称查找游戏。

在卡带驿站安装，下一次扫描就会使用。文件内容和已收录文件一致时，Continue 可以自动关联。只有名称、编号或街机压缩包文件名相符时，请在导入候选里确认。卡带可以更新或卸载，已经保存的游戏资料仍由游戏库保管。

这张卡带收录已发布的 Yinks 图鉴识别资料，以及 CPS1、CPS2、CPS3、IGS PGM 和 Neo Geo 的 956 个标准文件名。完整图鉴和图片在 Yinks 查看。安装此版本需要支持新版离线识别资料的 Continue Arcade。


# Offline Recognition Data

Continue can look up games by known file fingerprints, identifiers and names while importing offline.

Install from Cart Station to use the data on the next scan. Continue can link a game automatically when a known file fingerprint matches. When it finds a name, identifier or arcade archive filename match, review the suggestions during import. You can update or uninstall the Cart from Cart Station.

The Cart includes published Yinks recognition data and 956 standard filenames for CPS1, CPS2, CPS3, IGS PGM and Neo Geo. Visit Yinks for the full catalog and images. This release requires a version of Continue Arcade that supports the new offline data format.
